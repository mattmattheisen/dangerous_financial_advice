# Skeptical control

This directory contains agents whose objective is not to improve the recommendation, but to try to break it.

Planned modules:

- `assumption_auditor.py`
- `missing_information_agent.py`
- `falsification_agent.py`
- `uncertainty_agent.py`
- `skeptical_synthesis.py`

The control system should remain as independent as practical from the advisory narrative so it does not simply inherit the same framing.
